# 0.2.0 릴리스 동결 점검

날짜: 2026-11-12. 기능/버전 기준은0.2.0으로 고정한다. 공개 업로드나 태그 생성은 이 문서 자체로 수행되지 않는다.

## 이번 작업에서 완료할 범위

- 기존 README를 docs/DEVELOPMENT.md로 보존, 사용자용 영문 README/매뉴얼/릴리스 노트/타사 고지 작성.
- Help의 README/User Manual 및 F1 연결, 배포 문서·이미지 포함.
- 승인된 아이콘/프로젝트 로고를 포함한 변경 커밋.
- 임시 --ui-check 코드 제거, 유용한 로그/덤프 및 구버전 배포 산출물 정리는 유지.
- 0.2.0 컴파일·링크·구문·리소스·문서 경로·배포 일치 확인. 실제 확인 결과는 HANDOFF.md에 기록.

## 공개 전 미완료

- 최종 패키지의 GUI/Help 탐색 및 각 게임·지원 장치 실기 검증.
- SimConnect SDK DLL 공개 재배포 권리 확인. 소스 MIT 라이선스와 별개.
- 개인 pref/진단/프로젝트가 없는 별도 배포 staging/아카이브 검토.
- 사용자 지정 GitHub 저장소 연결 및 공개 업로드. 이번 작업에서는 하지 않음.

DCS Export 연동은 다음 버전 후보이며0.2.0 지원 목록에는 넣지 않는다. 이 파일은 내부 운영용이며 사용자 배포 문서 목록에서 제외한다.
